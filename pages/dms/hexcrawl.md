## The call

1. Find the terrain row and work out the **DC per day**.
1. Everyone in the party is either **navigating** or **watching**.
1. Each day of the hex, every navigator rolls Survival and every watcher rolls Perception. Turn each roll into a band, add the bands up and subtract the DC.
1. At the end of the hex, average the days, clamp to -2 to +2 and read the result. Move them on the map.

| Roll | Band |
| - | - |
| 5 or less | -2 |
| 6 to 9 | -1 |
| 10 to 11 | 0 |
| 12 to 14 | +1 |
| 15 or more | +2 |

## Terrain

DC per day = Difficulty + (navigators past three x Increase per Extra Navigator) + (animals x Increase per Animal).

| Terrain | Days per Hex | Difficulty per Day | Increase per Extra Navigator (3+) | Increase per Animal | Allows Animals |
| - | - | - | - | - | - |
| Paved road, down river | 0.5 | - | - | - | Yes |
| Dirt road | 1 | - | - | - | Yes |
| Plains, prairie | 1 | 0 | 0 | 0 | Yes |
| Animal track | 1.5 | no roll | none | none | Yes |
| Up river | 2 | - | - | - | Yes |
| Light forest, hills, scrub | 3 | 1 | 0.25 | 0.25 | Yes |
| Dense forest, jungle | 4 | 2 | 0.5 | 0.5 | Yes |
| Swamp | 4 | 2 | 0.5 | 0.5 | No |
| Mountains | 5 | 1.5 | 0.5 | 1 | Yes, if led |

- A hex of a day or less takes one roll. A longer hex takes one roll a day, and a part-day rounds up.
- **No drift, no roll:** any road, a beach or coast, a river bank, plains running alongside a forest. Nothing to get lost in. The lesser roads cost days, not safety.
- Pack animals carry the heavy gear and are barred from some ground.

## Navigators

Add the navigator bands for the day, subtract the DC, and keep a running total for the hex. At the end, divide by the number of days, round and clamp to -2 to +2.

| Result | What happened | Time |
| - | - | - |
| +1 or +2 | On course, or a drift fixed | On pace |
| 0 | Slowed | +25% of the hex |
| -1 | Delayed and drifting | +50%, one hex off |
| -2 | Lost | +50%, completely off course |

- A fourth navigator helps only if they are good at it. An unskilled one adds opinions, not direction.
- A long hex averages out, so a bad total after five rolls means they are lost badly.
- The return trip uses the same rules, unless the players do something that makes it easier. That is the DM's call.

## Watchers

Watchers use the same DC, so ambushes are likelier in dense forest than on plains. More watchers is only ever better. The animal and extra-person columns do not apply.

| Result | What happened |
| - | - |
| +1 or +2 | Spot the ambush early, or notice what is following |
| 0 | The encounter plays out as normal |
| -1 or -2 | Jumped |

Nobody watching counts as -2. Everybody watching leaves nobody navigating, so they drift. Watching matters when an encounter happens, and the encounter is rolled as usual.

## Worked example

Dense forest, DC 2 a day, four days. Three navigators with Survival +6, +3 and +1.

| Day | Rolls to bands | Sum | After DC |
| - | - | - | - |
| 1 | 18 = +2, 11 = 0, 6 = -1 | +1 | -1 |
| 2 | 20 = +2, 13 = +1, 4 = -2 | +1 | -1 |
| 3 | 15 = +2, 9 = -1, 13 = +1 | +2 | 0 |
| 4 | 10 = 0, 14 = +1, 8 = -1 | 0 | -2 |

The total is -4, which over four days is -1. They are delayed and drifting: 4 days becomes 6, and they end up one hex off.
